# 시장·기존 사업·경쟁 대안 조사

확인일: 2026-10-24 KST. 기업 공식 설명은 검증된 현장 성과나 독립적 평가와 구분한다. 공개 문서에서 확인하지 못한 기능을 '없다'고 단정하지 않는다.

## 1. 확인한 사실
- NICE인프라는 무인시스템 운영관리 회사이며 키오스크 외 ATM·주차 등의 사업을 설명한다[S1]. 키오스크 사업은 외식·교통·발권·유통 등의 맞춤 구축과 운영관리를 제공한다[S2].
- NICE의 낮은 화면, 저시력(고대비·확대), 음성 안내/키패드 주문은 기존 기능이다[S2]. 본 제안은 이를 새로 개발한 것으로 홍보하지 않는다.
- 채용공고의 무인솔루션기획실은 영업 실행계획, 손익/예산, 신규 BM, 고객니즈 서비스, AI·무인화 동향 및 제휴를 다룬다[S3]. 따라서 알고리즘보다 고객·검증·손익·도입조건을 함께 제시한다.
- Square는 2026-10-14 공식 발표에서 음성·터치 주문, 메뉴 질문/변경, 맥락 기반 추천을 소개했다[S4]. 도움을 제공하는 AI 키오스크 자체가 새롭다는 주장은 적절하지 않다. 운영효과 수치는 이 프로젝트의 근거로 전용하지 않는다.
- Toast 공식 지원문서는 메뉴/필수 옵션, 장바구니 수량·옵션 수정, 검토와 결제, 현금 고객의 계산원 연계를 설명한다[S5]. 이는 주문 기본 흐름과 사람 연결이라는 현실적 대안의 참고다.

## 2. 대안 비교(기획 판단)
| 대안 | 장점 | 제약·검토 포인트 | 본 제안의 위치 |
| --- | --- | --- | --- |
| 기존 UI 간소화·필수 오류 안내 | 낮은 운영복잡도, 모든 사용자 혜택 | 특정 시점의 어려움과 운영 원인 관측이 제한될 수 있음 | A 기준선, 우선 개선할 UX |
| 상시 수동 도움·직원 호출 | 사용자 통제, 오탐 자동개입 없음 | 도움 요청 자체를 찾지 못할 가능성 | B 비교 기준 |
| 음성/대화형 AI 주문 | 질문·수정 등 풍부한 상호작용[S4] | 환경 소음·정보 처리·비용·통합은 별도 검토 필요 | 미래 대안, 기본 구현에 도입하지 않음 |
| 조작 이벤트 기반 단계 지원 | 설명 가능, 서버/모델 없이 시연 | 임계값 오탐·거절·도메인별 조정 필요 | C, 실증 후 B보다 추가 가치가 있는지 판단 |

Square/Toast의 전체 제품을 기능 평가한 것은 아니다. 인용한 문서만으로 경쟁사 상황 감지·분석 기능의 부재 또는 본 제안의 우위를 입증하지 않는다.

## 3. 초기 타깃과 시장 검증 가설
1차: 동일 주문 UI를 여러 매장에서 쓰는 중소·중견 카페/외식 브랜드. 반복 학습·동일 조건 실증과 본사 KPI 관리가 가능하다는 가설이다.
2차: 키오스크 SW/운영 파트너. 기존 결제·접근성 기능을 유지하면서 이벤트 SDK와 안내 모듈을 연동하는 B2B2B 제안을 검토한다.
단일 저거래 매장은 구독비·통합비 대비 회수 가능성이 낮을 수 있어 기본 타깃에서 후순위로 둔다.

TAM/SAM/SOM과 실제 이탈률·직원 호출비용은 확인 자료가 충분하지 않아 숫자를 제시하지 않는다. 고객 인터뷰 5~8곳(제안값) → 무개입 베이스라인 로그 → 소규모 교차 실증 → 고객별 손익 견적 순으로 검증한다. 인터뷰/제휴는 아직 실시하지 않았다.
