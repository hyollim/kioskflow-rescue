최종 갱신: 2026-10-24 KST. 실행한 항목만 통과로 기록한다.

## Phase 1
- `npm test`: Vitest 3.2.4, 2개 파일 / 14개 테스트 통과(주문 가격 11, UI 3).
- `npm run build`: TypeScript 검사 및 Vite 7.1.12 production build 통과.
- UI 자동 테스트: 필수 온도 오류, 장바구니 수량·옵션 변경과 가격, 모의 결제 확인란, 완료·재시작, 빈 장바구니 차단, 카테고리·종료, 소개 이동 후 주문 보존.
- 초기 도구 실행 정지와 해결: 네이티브 의존성 대신 프로젝트 한정 WASM 빌드 도구, optional native watcher 제외. OS 보안 속성/권한은 변경하지 않음.
- 실제 브라우저 검증: 수행 전. 이후 결과를 추가한다.

## Phase 3
- `npm test`: 9개 파일 / 82개 테스트 통과(기존 40 + KPI 11 + 손익 17 + 저장 9 + 분석 UI/영속화 5).
- `npm run build`: TypeScript와 production build 통과.
- KPI: 빈 분모 null, 미종료 제외, 중복·고아 이벤트, 최초 종료·최초 응답, 30초 경계, 거절 후 수동도움 제외, 출처/모드 분리, 사전 정의 합성 12세션 전체 수치 검증.
- 손익: 기준 월 +628,000원·12개월 ROI 151.2% 수기값 일치, 도입 전후 차이, 초기비 중복 차감 방지, 0회 시도 고정비·0초기비·손익0, 음수·잘못된 입력·10%/20% 위험 경계·4개 시나리오 권고 전환 검증.
- 저장: 허용 필드 재구성·오래된 세션 단위 정리·큰 세션 시작 보존·재마운트 유지·저장 실패 메모리 fallback·확인 후 초기화 검증.
- 초기 저장 테스트에서는 Node 26의 Web Storage 전역이 jsdom 저장소를 가려 fixture가 실패했다. 테스트 자식 프로세스까지 NODE_OPTIONS=--no-experimental-webstorage를 전달해 브라우저 jsdom Storage를 사용한 뒤 전체 재검증했다. 사용자/OS 설정은 변경하지 않았다.
- 실제 production preview 브라우저: live 빈 데이터 ‘—’, 별도 synthetic 12세션·동일 A/B/C 75%와 비실험 안내, 기준 손익, 기기 이용료 직접 변경에 따른 보류 전환, 부정 프리셋 월 −2,217,000원·회수 불가 확인 및 캡처.
