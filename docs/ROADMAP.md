## 중단·보류 기준
인증/권한 문제를 우회하거나 다른 계정·저장소로 전환하지 않는다. Pages 추가 권한/설정이 필요하면 배포만 blocked 처리한다. 자동 푸시 실패 시 marker/관련 기존 로그만 읽고 원인을 기록한다. 유료 기능은 추가하지 않는다.
