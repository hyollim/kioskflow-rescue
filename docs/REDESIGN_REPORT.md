## 콘셉트와 주요 변경
**정보와 판단이 먼저 보이는 B2B 운영 플랫폼.** 녹색 장식·궤도·글로우·감성 카피를 줄이고 화면 목적과 다음 조작을 명확히 했다.
1. 216px 데스크톱 사이드바와 반응형 상단 내비게이션, 간결한 화면 제목, 일관된 여백과 8px 중심 라운드.
2. 카페 주문은 아이보리/베이지와 차콜 CTA로 구분. 직접 작성한 음료 SVG를 정돈하고 상품명·가격·선택·수량·오류·진행을 우선했다. 실험 설정과 6개 재현 컨트롤은 고객 화면 밖에 둔다.
3. 대시보드는 핵심 4개 KPI, 지원 이용/개입 결과, A/B/C 비교와 오류 화면, 익명 로그의 정보 계층으로 구성했다. 출처를 섞거나 가상 성과를 실제 개선으로 표현하지 않는다.
4. 사업성은 입력 3그룹과 별도의 의사결정/손익/비용 구성을 배치한다. 기준·긍정·보수·부정 선택과 직접 입력에 실제 계산 결과가 반응한다.

3. 모바일 손익 요약의 줄 높이/단위, 입력 필드 너비와 고정 헤더 아래 키보드 포커스 안정화. 최종 비교 PDF의 모바일 주석/푸터 간격도 개선했다.

## 기능 보존과 최종 회귀
- `npm run format:check`, `npm test`, `npm run build`, standalone 재생성 통과.
- **13개 테스트 파일 / 103개 테스트 통과 / 실패·보류 0개**. 기존 97개와 새 UI 회귀 6개다. 기존 테스트 수정은 변경된 제목/라벨 문구만 반영했으며 수식·규칙의 수치 기대값은 바꾸지 않았다.
- `src/domain`, `src/hooks`, 의존성 manifest/lockfile은 기준선과 byte diff가 없다. 주문 이동·초기화·선택·담기·시나리오, 손익/대시보드 렌더 전 계산은 보존했다. [무결성](qa-redesign-logic-integrity.json)
- 의존성 감사 **취약점 0개**. [실행 JSON](qa-redesign-tests.json), [감사](qa-redesign-dependency-audit.json)
- 실제 브라우저 **56개 상태**: 세 너비, 주문 완료/수정/수량/필수 옵션/결제 확인 오류, B 수동 도움·직원 호출 모의·취소, C 6종 재현·수락/거절/억제, 데이터 필터와 키보드 표 스크롤, 사업 가정 직접 입력·4개 시나리오를 검사했다.
- 검사 범위에서 페이지 가로 넘침, 14px 미만 본문, 44px 미만 고객 조작, 완전히 화면 안에 있는 조작의 가림, 숫자 입력 잘림, 자동 axe 위반은 0건이다. axe `color-contrast` 판정불가(비문자 기호·잘린/화면 밖 요소 등)는 통과로 합산하지 않고 별도 기록했다. 보조 색상 계산은 평면 배경의 텍스트에 한정한다. [브라우저 결과](qa-redesign-browser.json)
- C 재현은 별도 시나리오 로그로 기록되며 당시 직접 체험 로그 52건을 보존한 것을 확인했다. 이후 새 메뉴 캡처를 위한 직접 조작은 자체 체험 이벤트를 추가한다. [출처 분리](qa-redesign-event-consistency.json), [C 재현](qa-redesign-c-scenarios.json)
- 초기화는 빈 별도 origin `127.0.0.1:4186`에서 자체 생성한 2개 이벤트만 사용했다. 안전한 취소 초점, Tab/Shift+Tab 순환, Escape 시 데이터 보존/초점 복귀, 확인 후 0건·주문 초기화·합성 12세션/99이벤트 유지 확인. 기존 origin 로그를 지우지 않았다. [초기화 증거](qa-redesign-reset.json)
- 단일 HTML을 loopback HTTP로 실제 실행하여 내장 폰트/라이선스, 외부 runtime resource 0개, 기준 +628,000원과 부정 -2,217,000원/도입 보류 전환을 확인했다. [단일 HTML](qa-redesign-portable.json)

## 남은 한계와 배포
검사한 상태에서 미해결 잘림/겹침은 발견하지 않았다. 복잡한 표의 내부 가로 스크롤은 의도적인 설계다. 물리 기기·모바일 OS·실제 스크린리더·실매장 사용성은 추가 검증이 필요하다. 내장 한글 폰트로 단일 HTML이 약 3.1MB이며 실제 저사양 기기 성능은 미측정이다.

공개 Pages URL은 마지막 확인에서 404이며 설정/권한을 변경하지 않았다. 저장소 업로드와 CI 성공은 공개 배포 성공이 아니다. `file://` 직접 탐색은 브라우저 권한 제한으로 미검증이다. [실행·배포 상태](DEPLOYMENT.md)
